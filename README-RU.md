# tModLoader, API для модов на Terraria 

## Язык

**```Русский```** | [```English```](README.md)

tModLoader (TML) - это open-source модификация для Terraria, позволяющее создавать и играть в моды. TML расширияет ваши приключения в Terraria с помощью нового контента, созданного коммьюнити Terraria! TML позволяет создавать и играть в моды на Terraria в одиночку и с друзьями, с одним модом или нескольками модами: играйте, как вам хочется! Важно учесть, что всем вашим друзьям нужно установить TML, если вы хотите играть вместе; игроки из ванильной игры не могут играть с игроками TML.

## Инструкции

### Установка:
- Скачайте и распакуйте архив [из последнего релиза](https://github.com/Alexey-Proger/tModLoader-winarm/releases/latest)
- Установите Terraria (поддерживается только GoG Terraria, Terraria.exe должен находится в C:\GOG Games\Terraria)
- Запустите start-tModLoader.bat и немного подождите
- Готово!

### Установка модов:
- Скачайте моды (файлы .tmod)
- Скопируйте моды в C:\Users\%имя пользователя%\Documents\My Games\Terraria\tModLoader\Mods
- Запустите tModLoader, откройте Мастерская => Управление модами и включите ваши моды
- Готово!
